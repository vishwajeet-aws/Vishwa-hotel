# 🏨 Vishwa Hotel Management System

A modern **Hotel Management Web Application** built using full-stack technologies to manage hotel operations like room booking, customer management, and admin control in a simple and efficient way.

---

## 🚀 Live Demo
🔗 https://vishwa-hotel.vercel.app  

---

## 📌 Features

- 🛏️ Room Booking System  
- 👤 Customer Management  
- 📊 Admin Dashboard  
- 🔄 Booking Status Tracking  
- 📱 Responsive UI (Mobile + Desktop)  
- ⚡ Fast & Optimized Performance
